# KiVox

Herramientas para streamers: integración con los chats de Twitch y Kick, lectura de mensajes con TTS, conexión con OBS y chat general.

KiVox está en desarrollo. Las versiones disponibles se publican en **Releases**.

## Descargas

[Ver versiones publicadas](https://github.com/skowers/KiVox-Releases/releases)

Cuando haya una versión para probar, vas a encontrar ahí el paquete descargable y sus notas.

## Reportar un problema

Al informar un problema, incluí la versión de KiVox, tu versión de Windows y los pasos para reproducirlo.

**No compartas tokens OAuth, contraseñas de OBS ni archivos de configuración personal.**
